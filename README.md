# scanaislop.com

This repository controls the public GitHub organization profile for
[`scanaislop.com`](https://scanaislop.com).

The rendered profile is [`profile/README.md`](profile/README.md).

## Scan Your Code for AI Slop

Run this from any project root:

```bash
npx aislop scan
```

`aislop` is the open-source AI slop detector and deterministic quality gate for
AI-generated code. It catches repeatable agent leftovers before they reach pull
requests, CI, or production.
