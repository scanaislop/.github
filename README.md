# scanaislop.com

This repository powers the public GitHub organization profile for
[`scanaislop.com`](https://scanaislop.com), the AI slop detector and
deterministic quality gate for teams shipping with AI coding agents.

The rendered organization profile lives in
[`profile/README.md`](profile/README.md).

## Try aislop

Run an AI slop scan from any project root:

```bash
npx aislop scan
```

For a fresh one-off run against the latest npm release:

```bash
npx aislop@latest scan
```

Useful commands:

```bash
npx aislop@latest scan --changes
npx aislop@latest scan --staged
npx aislop@latest scan --json
npx aislop@latest fix
npx aislop@latest ci
```
